# Caracol Frontend

Aplicación Angular que genera y visualiza matrices con patrón de caracol (espiral), consumiendo la API del [backend caracol](https://github.com/juanleon8581/caracol).

## Requisitos previos

- Node.js v18+
- El backend debe estar corriendo en `http://localhost:3000` — ver [juanleon8581/caracol](https://github.com/juanleon8581/caracol)

## Instalación

```bash
npm install
```

## Levantar en desarrollo

```bash
npm start
```

La aplicación estará disponible en `http://localhost:4200`.

## Tests

```bash
npm test
```

## Build

```bash
npm run build
```
